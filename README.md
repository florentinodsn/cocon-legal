# cocon-legal

Pages légales de l'application **Cocon**, publiées via GitHub Pages.

Ce dépôt est public uniquement pour que GitHub Pages serve la page
gratuitement. Il ne contient aucun code de l'application.

- `index.html` — politique de confidentialité

La source de référence reste `legal/politique-de-confidentialite.md` dans le
dépôt de l'app. Toute modification doit être reportée ici, puis poussée : la
page est ce qu'Apple vérifie pendant la review.
